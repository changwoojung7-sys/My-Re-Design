# 🚀 자동 Git Commit & Push 규칙 (Mandatory Rule)

모든 단위 작업(기능 추가, 버그 수정, 파일 리팩토링, 문서 업데이트 등)이 완료되면 에이전트는 **요청을 받지 않아도 자동으로** 다음 배포 파이프라인을 실행합니다:

1. **타입 및 빌드 검증**: `npx tsc --noEmit` 검사 수행
2. **Git 변경사항 스테이징**: `git add .`
3. **직관적인 커밋 메시지 작성 및 커밋**: `git commit -m "<작업 내용을 명확히 설명하는 커밋 메시지>"`
4. **원격 저장소 자동 푸시**: `git push origin main`
5. **결과 보고**: 응답 서두에 ✅ (초록색 체크마크)와 함께 푸시 완료 내역을 사용자에게 안내합니다.
